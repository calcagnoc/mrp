# MRP SOAP

Formulatore e registro di produzione per sapone a freddo (uso personale).

- App: https://calcagnoc.github.io/mrp/
- I dati (ricette, batch, acquisti, magazzino, diario) stanno nel repository privato `mrp-dati`, un file JSON per tabella; l'app li legge e li scrive con un token GitHub inserito nelle Impostazioni.
- Il sorgente che genera `index.html` è `build.py` (nel laboratorio di Claude); non modificare `index.html` a mano.
